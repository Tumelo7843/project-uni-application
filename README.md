# UniPath South Africa

A responsive university discovery website designed to help students explore South Africa’s public universities by province, city, and study focus.

Live project: https://project-uni-application.vercel.app/

## Overview

UniPath South Africa makes it easier to compare universities and discover programmes, campuses, and application information in one place. Users can:

- Browse universities by province
- Search by institution, city, or study area
- Explore each university’s key focus areas
- View application windows where available
- Visit official university and application websites

## Features

- Province-based filtering
- Search and discovery tools
- Clean, modern UI for mobile and desktop
- Direct links to university and application portals
- Information for public universities across South Africa

## Tech Stack

- React
- Vite
- HTML
- CSS

## Local Development

1. Install dependencies:
   npm install

2. Start the development server:
   npm run dev

3. Open the local Vite URL shown in the terminal.

## Production Build

To build the project for production:

npm run build

## Project Structure

- src/ - React app source files
- index.html - main entry page
- style.css - site styling
- script.js - supporting front-end logic
- universities.js - university data
- package.json - project scripts and dependencies
